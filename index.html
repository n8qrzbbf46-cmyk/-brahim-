API Mantığı Nasıl Çalışır?

Bu web sitesi, gerçek bir backend API ile nasıl iletişim kuracağını simüle eder.

1. İstek Oluşturma
Kullanıcı mesajı veya dosya, JavaScript ile JSON formatına dönüştürülür ve fetch() ile API endpoint'ine POST edilir.
2. Sunucu & Model
Gerçek hayatta: Node.js/Python backend + Grok / OpenAI / Claude API çağrısı yapılır. JWT veya Bearer token ile kimlik doğrulama.
3. Yanıt İşleme
API'den dönen JSON parse edilir. Mesajlar, analiz sonuçları ve metadata frontend'de render edilir. Hata yönetimi ve loading state gösterilir.
// Gerçek API entegrasyonu örneği (JavaScript)
async function callGrokAPI(userMessage, apiKey) {
  const res = await fetch("https://api.x.ai/v1/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${apiKey}`,
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      model: "grok-3-latest",
      messages: [{ role: "user", content: userMessage }]
    })
  });
  const data = await res.json();
  return data.choices[0].message.content;
}
Bu sayfa tamamen frontend simülasyonudur. Gerçek yapay zeka API'si (xAI Grok, OpenAI vb.) ile tam entegrasyon için backend sunucu gerekir.
