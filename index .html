TEKNİK DETAY

API Mantığı Gerçekten Nasıl Çalışır?

Bu site, gerçek bir backend + yapay zeka API'si ile nasıl iletişim kuracağını %100 gerçekçi şekilde simüle eder.

1. İstek Oluşturma
Kullanıcı mesajı, dosya veya video konsepti JavaScript ile JSON'a dönüştürülür ve fetch() ile ilgili API endpoint'ine POST edilir. Gerçek hayatta bu backend'e gider.
2. Sunucu + Model Katmanı
Gerçek hayatta: Node.js / Python FastAPI backend + Grok / Claude / GPT-4o API çağrısı yapılır. JWT / Bearer token ile güvenli kimlik doğrulama. Rate limiting ve caching uygulanır.
3. Yanıt İşleme & Render
API'den dönen JSON parse edilir. Mesajlar, analiz sonuçları, video storyboard'ları ve metadata frontend'de güzelce render edilir. Hata yönetimi, loading state ve retry mekanizması gösterilir.
// Gerçek xAI Grok API entegrasyonu örneği (JavaScript)
async function callGrokAPI(userMessage, apiKey) {
  const res = await fetch("https://api.x.ai/v1/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${apiKey}`,
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      model: "grok-3-latest",
      messages: [{ role: "user", content: userMessage }],
      temperature: 0.7,
      max_tokens: 2048
    })
  });
  const data = await res.json();
  return data.choices[0].message.content;
}
Bu sayfa tamamen frontend simülasyonudur. Gerçek yapay zeka API'si (xAI Grok, OpenAI, Anthropic vb.) ile tam entegrasyon için backend sunucu + API anahtarı gerekir.
